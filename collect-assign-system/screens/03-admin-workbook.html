연동 데모
이 화면은 실제 Excel 워크북 하나를 그대로 흉내 낸 거예요. 아래 탭 5개가 워크북 시트 5개와 같습니다. 지원자·인터뷰어 화면에서 제출된 내용이 ②③ 탭에 자동으로 쌓이고, 아래 "배정 실행" 버튼을 누르면:
  1. ②인터뷰어가용시간을 보고 ①슬롯마스터의 빈 시간칸을 채우고
  2. ③지원자접수를 "가능시간이 적은 사람부터" 순서로 빈 슬롯에 짝지어주고
  3. 결과를 ④배정결과 탭에 정리합니다 (끝내 못 맞춘 사람은 "수동조율필요"로 표시)
실제 Excel에서는: VM_인터뷰_배정관리.xlsx 워크북 상단 "자동화" 탭에 미리 등록해둔 배정 스크립트(Office Script)를 클릭 한 번으로 실행하는 것과 똑같습니다. 예약된 자동 실행이 아니라 담당자가 필요할 때 직접 누르는 방식입니다.
실제 실행 시 주의사항 (테크팀 답변, 2026.07.27 확인)
  • 처리 속도: 약 20행에 30초 정도 걸립니다. 한 번에 몰아서 돌리기보다, 자주(예: 하루 여러 번) 소량씩 실행하는 것을 권장합니다.
  • 동시 접근: 스크립트 실행 중 다른 사람이 워크북을 "보는" 것은 안전하지만, 같은 시간에 데이터를 "수정·추가"하면 예기치 않은 문제가 생길 수 있습니다. 실행 직전에는 다른 담당자에게 잠시 편집을 멈춰 달라고 안내하세요.
  • 실행 권한: 베델 계정 보유자는 워크북 화면에서 스크립트를 바로 실행할 수 있습니다. 그 외 계정은 Power Automate와 연결된 목록(List)에 항목을 추가하는 방식으로 실행을 트리거할 수 있습니다(별도 설정 필요 — 워크북 담당자 확정 후 결정).
