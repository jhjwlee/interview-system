# collect-assign-system (수집·배정형 데모)

이 폴더는 `interview-system`(예약형) 데모와 별도로 만든, **베델 계정 없이 JWPUB 계정만으로 운영 가능한** 인터뷰 배정 구조의 데모입니다. `interview-system` 폴더는 그대로 유지되며, 이 폴더는 그것을 대체하지 않고 새 안(수집·배정형)을 보여주기 위해 병행 운영됩니다.

배경: 테크팀 답변으로 SharePoint 목록 관리, Power Automate 플로우 구성이 베델 계정 없이는 불가능하다는 점이 확정되어, 전체 구조를 Excel + Microsoft Forms + Teams 파일 탭 중심으로 다시 설계했습니다. 자세한 배경은 `2026.07.26_인터뷰시스템_베델계정불가_재구성안.docx` 문서를 참고하세요.

## 데모 화면 구성

- `index.html` — 허브 페이지
- `screens/00-overview.html` — 5단계 흐름 설명
- `screens/01-applicant-submit.html` — 지원자 가능시간 제출
- `screens/02-interviewer-submit.html` — 인터뷰어 가능시간 제출
- `screens/03-admin-workbook.html` — 관리자 워크북(5개 시트 화면) + "배정 실행" 버튼
- `screens/04-helpdesk.html` — 문의하기

이 화면들은 브라우저 `localStorage`(키: `vm2027_collectassign_demo_v1`)에 데이터를 저장해 화면 간 연동을 흉내 냅니다. `interview-system` 데모와는 다른 키를 사용하므로 두 데모는 서로 영향을 주지 않습니다.

## 실제 배정 로직 코드

`scripts/assignment-office-script.ts` — 실제 Excel Online에 붙여넣어 바로 실행할 수 있는 Office Script(TypeScript)입니다. `assets/store.js`의 `runAssignment()` 함수는 이 스크립트와 동일한 로직을 자바스크립트로 옮긴 것으로, 데모 화면의 "배정 실행" 버튼이 이것을 호출합니다. 두 코드는 같은 설계 문서(재구성안 2-3절)를 기준으로 나란히 작성되었으므로 로직이 일치합니다.

배정 로직 요약:
1. 인터뷰어가 제출한 가능 날짜 × 가능 시간의 모든 조합을 슬롯마스터의 빈 슬롯에 채웁니다(1일 최대건수 초과 없이).
2. 지원자는 가능시간을 적게 제출한 사람부터 우선 배정합니다.
3. 이미 인터뷰어가 배정되지 않은 슬롯, 정원이 찬 슬롯은 건너뜁니다.
4. 끝까지 배정받지 못한 지원자는 "수동조율필요"로 표시합니다.
5. 재실행해도 이미 배정된 건은 건드리지 않아 여러 번 실행해도 안전합니다.

## 실제로 구축할 때 — 체크리스트

1. **Excel 워크북 생성**: `VM_인터뷰_배정관리.xlsx`를 담당자의 OneDrive 또는 Teams 채널 파일함에 생성하고, 시트 5개(①슬롯마스터, ②인터뷰어가용시간, ③지원자접수, ④배정결과, ⑤헬프데스크)를 문서에 정의된 컬럼 그대로 만듭니다.
2. **Forms 3개 생성**: 지원자 신청용, 인터뷰어 가용시간 등록용, 헬프데스크 문의용. 외부 응답 허용 여부는 테넌트 설정에서 미리 확인합니다(Bethel 계정 불필요, 별도 확인 필요).
3. **Office Script 등록**: 워크북을 Excel Online에서 열고 상단 "자동화" 탭 → "새 스크립트"에 `scripts/assignment-office-script.ts` 내용을 그대로 붙여넣고 저장합니다.
4. **Forms 응답 → 시트 반영**: Forms 응답을 다운로드하거나 복사해 ②·③ 시트에 붙여넣습니다(현재는 수동 — Power Automate 자동 연결 없이도 동작하는 구조입니다).
5. **배정 실행**: "자동화" 탭에서 저장한 스크립트를 클릭해 실행합니다. 필요할 때마다(예: 주 1~2회) 담당자가 직접 실행합니다.
6. **Teams 통합**: 워크북 파일을 팀 채널의 파일함에 올리고, 채널 상단에 "+" → "Excel"로 탭을 추가해 팀원들이 바로 볼 수 있게 합니다(일반 팀원 권한으로 가능).
7. **결과 검증 및 통지**: ④배정결과 시트를 확인하고 "수동조율필요" 건을 우선 처리한 뒤, 담당자가 개별 이메일 또는 JW Hub 공식 채널로 안내합니다.

## 확인이 아직 필요한 사항

- JWPUB 계정에 Office Script 실행 라이선스가 제공되는지
- Teams 채널 파일 → Excel 탭 추가가 일반 멤버 권한으로 가능한지
- Forms 외부 응답 허용이 테넌트 차원에서 이미 설정되어 있는지
- 워크북을 실제로 소유·관리할 담당자가 누구인지
