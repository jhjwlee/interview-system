인터뷰 배정 시스템 — 수집·배정형 데모

Excel + Microsoft Forms + Teams 파일 탭만으로 구성한 새 운영 방식입니다. 베델 계정 없이 JWPUB 계정으로 운영 가능한 구조로 다시 설계했습니다.

모든 화면은 브라우저에 저장되는 데이터로 서로 연동되어 있어, 실제 흐름처럼 눌러보며 확인하실 수 있습니다.

← 기존 예약형 데모(interview-system)로 돌아가기
💬
이 시스템은 이렇게 움직여요
  1. 인터뷰어가 가능한 날짜·시간을 알려줍니다 (아직 아무것도 확정되지 않음)
  2. 지원자도 가능한 시간을 여러 개 골라 알려줍니다 (역시 확정 아님, "대기" 상태로 쌓임)
  3. 관리자가 워크북 화면에서 "배정 실행" 버튼을 누르면 — 쌓여 있던 두 데이터를 컴퓨터가 자동으로 짝지어줍니다
  4. 매칭 안 된 사람은 "수동조율필요"로 따로 표시되어, 관리자가 직접 처리합니다
  5. 관리자가 최종 확인 후 개별로 이메일 등으로 안내합니다 (자동 발송 없음)

🎬 시연 순서 (추천)

이 순서대로 눌러보시면 "가능시간 제출 → 배정 실행 → 결과 확인" 흐름이 자연스럽게 이어집니다.
  1. 🗓️ 인터뷰어 제출 화면에서 이름·이메일 입력 후 날짜 하나와 시간 1~2개를 골라 제출
    → 관리자 워크북 ②인터뷰어가용시간 탭에 쌓입니다 (아직 슬롯은 안 만들어짐)
  2. 📝 지원자 제출 화면에서 이름·이메일 입력 후 방금 인터뷰어가 고른 것과 겹치는 날짜·시간을 골라 제출
    → ③지원자접수 탭에 "배정대기" 상태로 쌓입니다
  3. 🗂️ 관리자 워크북으로 이동해 상단 "배정 실행" 버튼 클릭
    → ①슬롯마스터에 인터뷰어가 채워지고, ③지원자가 짝지어져 ④배정결과 탭에 나타납니다
  4. (선택) 💬 문의하기에서 문의를 하나 남긴 뒤, 다시 관리자 워크북으로 돌아가 ⑤헬프데스크 탭에서 확인
  5. 시연을 다시 처음부터 보여줘야 한다면 이 페이지의 "데모 초기화" 버튼을 눌러 리셋
